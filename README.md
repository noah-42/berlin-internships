## Access Jobscout via API

For direct access to the wider Jobscout data, start at **[noah42.com/jobscout](https://www.noah42.com/jobscout/)**.

1. **Contact Noah for the password.**
2. Follow the page's access instructions to unlock your token and connect your agent or coding tools.
3. Keep the API token private. The access password is for unlocking access; the token is the API credential, not a password to publish or commit.

The GitHub list and downloads above are public and do not require the password. API access is separate; this repository does not contain API credentials.
